# Figma SVG exports

以下のSVGをFigmaにドラッグ&ドロップすると、各デザイン案をベクター中心のカンプとして表示できます。

- `editorial-monochrome.svg`
- `vertical-gallery.svg`
- `columbia-corporate.svg`
- `unibio-culture.svg`

対応元ページ:

- `http://localhost:3001/concepts/editorial-monochrome`
- `http://localhost:3001/concepts/vertical-gallery`
- `http://localhost:3001/concepts/columbia-corporate`
- `http://localhost:3001/concepts/unibio-culture`

補足:

- 画像部分はFigma上で差し替えやすいよう、プレースホルダーの矩形で表現しています。
- 文字と余白、構図、配色の確認・編集を目的にしたSVGです。
